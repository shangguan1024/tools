# Layer 3D 可视化工具设计

## 概述

基于 Three.js 的浏览器端 3D 可视化工具，解析文本日志中的 layer 信息，将每个 layer 渲染为实体方块，按日志顺序在 z 轴依次堆叠，支持鼠标交互查看层叠效果。

## 日志格式

```
dump layer:
layer：id 1 x 10.0 y 10.0 x 20.0 y 20.0
layer：id 2 x 10.0 y 10.0 x 20.0 y 20.0
```

- 每行以 `layer：` 开头（注意中文冒号）
- 字段：id, x1, y1, x2, y2
- x1/y1 为左下角坐标，x2/y2 为右上角坐标

## 界面设计

### 布局
- **顶部工具栏**：水平排列的控制按钮
- **中央 3D 视图**：占据主要区域的全屏 3D 场景

### 工具栏按钮
| 按钮 | 功能 |
|------|------|
| 读取日志 | 解析 layer_log.txt 并渲染 |
| 重置视角 | 恢复默认相机位置 |

### 3D 场景
- 每个 layer 渲染为**实体方块**
  - 底面尺寸：根据日志坐标计算 (x2-x1) × (y2-y1)
  - 高度：固定 1 单位
  - 颜色：统一灰色
- **文字标签**：在方块顶面中央显示 layer ID
- **z 轴顺序**：按日志中出现顺序依次升高（0, 1, 2, ...），形成层叠视觉效果

### 3D 交互
| 操作 | 功能 |
|------|------|
| 鼠标左键拖动 | 旋转视角 |
| 滚轮 | 缩放 |
| 鼠标右键拖动 | 平移视角 |

## 技术栈

- **Three.js** (r160+): CDN 引入
- **OrbitControls**: 相机控制
- **TextGeometry + FontLoader**: 3D 文字渲染
- **单 HTML 文件**: 无构建步骤，直接浏览器打开
